# Video OS Studio Visual Identity

## Style Prompt
A dark, technical video-production workstation aesthetic. The interface and generated motion assets should feel precise, engineered and editorial: charcoal canvas, safety-yellow focus accents, high-contrast typography, restrained green for validated/success states and red only for failures. Motion should clarify information rather than decorate it.

## Colors
- `#080B0F` — primary canvas
- `#111820` — panels / motion cards
- `#F5F7FA` — primary text
- `#FFC400` — focus / key metrics / active motion
- `#55D187` — success / controlled state
- `#FF6565` — risk / failure only

## Typography
- UI and generated motion: system sans-serif / Arial fallback
- Headline hierarchy: heavy 800–950 weight
- Supporting labels: uppercase, tracked, restrained

## Motion
- Fast but controlled entrances using 0.35–0.7 second equivalents
- Prefer directional slide, scale and progress motion
- End-state layout must be readable before animation is added
- Hold the finished information long enough to read

## What NOT to Do
- No pastel gradients or glossy 3D blobs
- No playful bounce-heavy motion
- No infinite loops
- No random/time-dependent animation
- No decorative motion that competes with the spoken message
